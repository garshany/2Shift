# Установка TwoShift

## Установка

1. Откройте `TwoShift.dmg`.
2. Перетащите `TwoShift.app` в `Applications`.
3. Запустите `TwoShift`.
4. В верхней панели macOS появится значок `2⇧`.

## Разрешения macOS

TwoShift попросит два разрешения:

- `Accessibility` / `Доступность` — нужно, чтобы приложение могло отправлять `Cmd+C` и `Cmd+V`.
- `Input Monitoring` / `Мониторинг ввода` — нужно, чтобы приложение ловило двойной `Shift` глобально.

Окно настроек само обновляет статусы после выдачи разрешений. Обычно перезапуск не нужен. Если macOS уже выдала оба разрешения, но слушатель клавиатуры не поднялся, TwoShift покажет кнопку `Перезапустить TwoShift`.

Если после обновления или пересборки галочки в macOS выглядят включенными, но двойной `Shift` не срабатывает, сбросьте права только для TwoShift:

```bash
scripts/reset_permissions.sh
scripts/install_local.sh
```

После запуска заново выдайте оба разрешения. Для локальных/dev-сборок `scripts/install_local.sh` делает этот сброс автоматически, если подпись приложения изменилась. Это нужно только для ad-hoc подписи; notarized Developer ID/App Store сборка должна вести себя стабильнее.

## Проверка

1. Откройте TextEdit, Telegram или браузер.
2. Напишите `ghbdtn`.
3. Выделите текст.
4. Нажмите `Shift` два раза.

Результат должен стать `привет`.

Запасной хоткей: `Cmd+Shift+Space`.

На стандартной macOS-раскладке `Russian` поддерживаются знаки препинания: например `Ghbdtn^ vbh& Rfr ltkf? Lf!` превращается в `Привет, мир. Как дела? Да!`.

## Диагностика

Если что-то не работает:

1. Нажмите `2⇧` в верхней панели macOS.
2. Откройте `О TwoShift...`.
3. Нажмите `Скопировать диагностику`.
4. Отправьте этот текст разработчику.

Если `Мониторинг ввода` уже разрешен, но `Слушатель клавиатуры` неактивен, нажмите `Обновить статусы` в настройках. Если macOS всё равно не подняла listener, появится кнопка `Перезапустить TwoShift`.

## Ограничения

- В password fields и secure input приложение не работает.
- Некоторые приложения могут блокировать синтетическую вставку.
- Форматирование rich text в MVP не сохраняется.
