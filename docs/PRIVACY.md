# TwoShift Privacy Notice

TwoShift is local-only software.

## What the app reads

When you trigger conversion, TwoShift temporarily copies the selected text through the macOS clipboard, converts the text locally, pastes the converted text, and restores the previous clipboard contents.

## What the app does not do

- Does not send text to a server.
- Does not use analytics.
- Does not log selected text.
- Does not store conversion history.
- Does not read password fields or secure input fields.

## macOS permissions

TwoShift needs Accessibility and Input Monitoring because macOS requires explicit user permission for global keyboard shortcuts and synthetic copy/paste events.
