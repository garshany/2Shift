# TwoShift 0.1.0

Initial alpha release.

## Added

- Menu bar macOS utility for fixing selected text typed in the wrong keyboard layout.
- Double `Shift` shortcut.
- Backup `Cmd+Shift+Space` shortcut.
- English/Russian bidirectional conversion with auto direction detection.
- Clipboard preservation after conversion.
- Russian settings UI.
- About/diagnostics window with copyable support information.
- Permission status for Accessibility and Input Monitoring.
- Launch at Login toggle.
- DMG and ZIP packaging scripts.
- Developer ID signing and notarization pipeline.

## Known limitations

- Not notarized until a Developer ID certificate and notary profile are configured.
- Secure input and password fields are not supported.
- Rich text formatting is pasted back as plain text.
- Custom hotkey editor is not implemented yet.
