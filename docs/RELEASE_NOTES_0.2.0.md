# TwoShift 0.2.0

Первый публичный релиз.

## Что умеет

- Конвертирует выделенный текст между английской и русской раскладками (`ghbdtn` → `привет`, `руддщ` → `hello`) в любом приложении macOS.
- Направление определяется автоматически.
- Триггеры: двойной `Shift` и настраиваемое сочетание (по умолчанию `⇧⌘Space`).
- **Новое:** после конвертации системная раскладка переключается на язык результата; без выделения двойной `Shift` просто переключает EN ⇄ RU. Отключается в настройках.
- Буфер обмена восстанавливается после вставки.
- Русский интерфейс настроек, ассистент выдачи разрешений, запуск при входе, окно диагностики.

## Ограничения

- Сборка подписана ad-hoc (без Developer ID / нотаризации): при первом запуске macOS попросит подтвердить открытие в «Системные настройки → Конфиденциальность и безопасность».
- Защищённые поля ввода (пароли) не поддерживаются.
- Rich text вставляется как обычный текст.
